# CodeAlpha Task 2 - Social Media Web Application

## 📌 Project Overview

This project is a simple Social Media Web Application developed as part of my internship task.

The application allows users to register, log in, create posts, like posts, comment on posts, follow other users, and view their profile.

## 🚀 Features

- User Registration
- User Login and Logout
- Create Posts
- Like / Unlike Posts
- Comment on Posts
- Follow / Unfollow Users
- People to Follow Section
- User Profile Page
- Followers and Following Count
- Display User Posts
- Responsive User Interface

## 🛠️ Technologies Used

- Python
- Django
- HTML5
- CSS3
- SQLite
- Visual Studio Code
- Git & GitHub
